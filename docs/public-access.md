# 公网访问（Cloudflare Tunnel）

让装在一台常开电脑上的智策，通过一个公网网址被外面访问——**不需要公网 IP，不需要在路由器上做端口映射**。

目标场景是一个 5–30 人的小团队：没有机房，只有一台常开的 PC，同事在外面也想用。

## 怎么开

**设置 → 网络 → 公网访问** 的开关。默认关。

开启前界面上会列一份清单，任何一项不满足就不给开：

| 条件 | 为什么是硬门 |
|---|---|
| 已完成首启、有管理员账号 | 没有口令的实例挂到公网等于开门 |
| 登录验证码已开启 | 公网地址一定会被扫描，没有验证码撞库可以慢慢试 |
| 接口文档未对外开放 | 开着等于先给对方一份接口清单 |
| 当前平台支持 | 组件按平台钉版本，没有校验和的平台一律拒绝下载 |
| 勾选「我已知悉流量经过第三方边缘」 | 见下面第 3 条，这是产品承诺的显式例外 |

还要**再输一次你的登录口令**。库里存的是哈希，拿不到明文就无法判断它够不够强，也无法证明点按钮的人知道它。口令只用于这一次校验，不落盘。

## 1. 地址是一次性的

试用隧道每次重新开启都会换一个随机网址，**服务重启也不会自动恢复**（故意不做自动重连：那样只会让你之前发给同事的链接悄悄失效）。

需要长期固定域名，得配 Cloudflare 的正式（named）隧道——**本版本还没有做**，因为它需要你自己有 Cloudflare 账号和域名，没有凭据就没有验证过，不写没验证过的功能。

## 2. 公网安全模式（默认开，不建议关）

开启后，**从公网进来的请求**不能使用：

- 终端、浏览器、远程桌面、远程手机
- 本机文件浏览
- 接口文档、TLS / 更新 / 备份管理

本机与内网的使用完全不受影响。

这一条的存在理由很直接：专家能直接操作这台电脑。认证一旦被绕过，风险等级是"这台机器沦陷"，不是"泄露几个文件"。把公网进来的流量能碰的东西砍掉，风险才从前者降到"账号泄露"。

关掉它需要显式操作，确认框会用红色警告再问一次。

判定"这个请求是不是从隧道来的"依据的是 Cloudflare 边缘统一注入的 `Cf-Connecting-Ip` 请求头。cloudflared 没有自定义请求头注入能力（实测 `--header` 标志不存在），而本机直连看到的源地址永远是 `127.0.0.1`，所以只能用这个头。**伪造它只会让本机请求被当成远程而降权，不能提权**——方向是安全的。

## 3. 这与「数据不出内网」是冲突的，所以单独说

产品的默认承诺是不出本机/内网。开公网访问**就是**打破它：对话内容、上传的文件、登录凭据都会经由 Cloudflare 的边缘节点转发。

对合规有要求的组织，请先确认这一点可以接受再开。

## 4. 国内可达性不稳定

`*.trycloudflare.com` 与 Cloudflare 边缘在国内的可达性随运营商与时间波动。所以：

- 开启后产品会**真的从公网地址访问一次自己**，成功才显示"已连通"；只看到进程起来不算。
- 刚建好时可能显示"已建立·未验证"——Cloudflare 生效需要几秒到几十秒，界面上有「重新验证」。
- 有公网 IP 的团队，优先用「端口映射 + 动态 DNS + 产品自带 HTTPS」那条路，不经过第三方。
- 只给固定几个人用，**私网组网（Tailscale / ZeroTier）安全性更好**：不暴露任何 HTTP 面。

## 5. 磁盘与组件

公网访问组件（cloudflared，约 53 MB）**不随安装包分发**——那会让每个包白白涨 23%，而它是纯可选功能。第一次开启时才下载，下载后按钉死的 SHA-256 校验，校验不过直接报错。

组件与隧道配置都放在 `%USERPROFILE%\.octop\tunnel\` 下，不写系统 PATH、不往 `~/.cloudflared` 写，避免和你自己装的 cloudflared 互相踩。

cloudflared 版权归 Cloudflare，Apache-2.0 许可，随包声明写在同目录的 `LICENSE.cloudflared.txt`。

## 6. 关掉

把开关关掉即可。产品会验证关闭后公网地址确实不再应答。

审计日志（**管理 → 安全防护 → 审计**）里留有 `tunnel.start` / `tunnel.stop` / `tunnel.safe_mode` 记录，谁开的、什么时候、安全模式开没开，都在。

## 验收

```bash
python scripts/verify/tunnel_probe.py --python .venv/Scripts/python.exe
```

起独立实例、开真隧道、**从公网地址**跑 13 项断言再关掉，覆盖"通不通""拦不拦""伪造头是否失败关闭"三组。
