装起来

安装版

  1. 双击 .exe，按向导装到当前用户目录（不需要管理员权限）。
  2. 从开始菜单启动 智策，它会在本机起服务并打开窗口。
  3. 首次启动进入初始化向导：验证口令 → 数据库（默认本机 SQLite）→ 建管理员 → 配模型（可跳过）。
  4. 一次性引导口令在服务器控制台的黄框里，也写在 %USERPROFILE%\octop-login.txt。

便携版

  1. 解压到任意目录（路径含空格也可以）。
  2. 双击 start.bat；需要换端口或数据目录：start.bat --port 8090 --home D:\zcagent-data。
  3. 浏览器打开 http://127.0.0.1:8088，走同一套初始化向导。
  4. 数据默认落在解压目录的 .\data，整个文件夹拷走就是迁移。

模型 Key 在「模型」页填，支持任意 OpenAI 兼容端点。不配模型也能先用完全部界面。

先校验，再运行

在 PowerShell 里算出文件的 SHA256，和上面对照：

Get-FileHash .\{{zip.name}} -Algorithm SHA256

大小以精确字节数为准（安装版 {{exe.bytes}} 字节、便携版 {{zip.bytes}} 字节）。Windows 资源管理器显示的 MB 会因单位换算略有差异。

数据、更新与卸载

  • 数据在哪：默认 %USERPROFILE%\.octop（便携版为 .\data），含账号、专家、对话与记忆、技能与模型配置。
  • 更新：应用内「应用设置 → 应用更新 → 检查更新」。默认不检查公共源，避免装上别人的构建；内网自建索引时设 OCTOP_UPDATE_JSON_URL 与 OCTOP_UPDATE_SIMPLE_URL 才会启用。
  • 卸载：安装版从「应用和功能」卸载；便携版直接删目录。两者都不动数据目录，重装即可继续用。

已知限制

  • 「工作台 / 终端」在 Windows 上不可用：该功能依赖 pty，按设计仅在 Linux/macOS 提供，不是本安装包的问题。
  • 只出 Windows x64 包。macOS / Linux / ARM64 的构建定义都在仓库里，按平台逐个放开并各自验收。
  • 未签名，因此首次运行有一次 SmartScreen 提示。
  • 安装版需要 WebView2 运行时；缺失时安装器会提示安装。
