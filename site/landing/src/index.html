看下载与校验步骤
  • 安装版需要 Microsoft Edge WebView2 运行时（较新的 Windows 10 已内置，缺失时安装器会提示）。
  • 首次启动进入初始化向导：验证口令 → 数据库 → 建管理员 → 配模型（可跳过）。
  • 模型 Key 支持任意 OpenAI 兼容端点，在「模型」页填即可。

给要审计代码或改造成自己产品的团队。脚本会在 ~/.octop 下用 uv 建一个隔离的 Python 3.12 环境，不碰系统 Python。 

irm {{INSTALL_PS1_URL}} -OutFile install.ps1
.\install.ps1 -FromSource

装好后初始化并启动：

octop init
octop run
  • -FromSource 不能省。省掉它，脚本会去 PyPI 装一个同名的 octop 包——装出来的不是智策。
  • 命令行入口仍然叫 octop：产品沿用了既有的协议头与数据目录 ~/.octop，改了会断掉已有数据的兼容性。
  • 我们不发布公共 PyPI 包；内网自建索引时在应用设置里填索引地址即可。
  • 脚本本体就是仓库里的 scripts/install.ps1，官网只负责发它，不维护副本。

为什么选{{NAME_ZH}}

一次部署，人人有专属助手

一台机器跑一套服务，全组共用。按岗位给每个人建一位专家——销售的小通、工程师的小码—— 各自的记忆、模型与工作区互相独立，不用抢同一个上下文。

知识留在公司里

知识库、文档与全部对话都存在你自己部署的那台机器上。需要接外部服务时，连接器与凭据同样由你保管； 敏感信息在离开工作区前会自动脱敏，高风险工具与命令要显式审批。

一句话交代，它按时自己干

定时任务不用写 Cron 表达式。直接用大白话说清楚「什么时候、做什么」， {{NAME_ZH}}替你解析成计划并落到服务端——服务在跑，它就一直按时执行， 不需要谁开着浏览器盯着。

到了点，专家带着同一套技能、同一份记忆去执行：整理待办、复盘本周、 汇总数据写进工作区，或者把结果直接推到群里。Web 控制台、IM 消息与定时任务 共用同一条处理链路，所以定时跑的活和随手问的活，用的是同一副脑子。

装上就有一整个生态

这是{{NAME_ZH}}最值钱的部分：不是一个空壳聊天框等你从零配。装完之后， 55 个现成的市场专家、数百个可一键安装的技能、26 个内置连接器 与 10 个 IM 通道直接可用——按一下「从市场创建」或「安装」，一位配好技能、 接好工具的同事就上岗了。

专家市场：按行业挑一个，不用从零写提示词

「专家」是一位有独立人格、工作区、记忆和技能包的 AI 同事。市场里的专家不是空壳模板—— 每个都写清了擅长什么、从哪一步开始、交付物是什么，还预装 6 个技能。 按行业筛一下就能用：

  • 法律：合同起草、诉讼策略、法规检索——条款审查与尽职调查，配合使用
  • 金融：财报分析、量化回测——三表解读、财务造假识别、完整报告生成
  • 医疗健康：病历分析、护理方案、健康报告、临床辅助
  • 人力行政：简历筛选——漏斗式量化评估到结构化信息提取
  • 技术与内容：自动化测试、脚本拆解、分镜设计、视频剪辑——从 TDD 到 FFmpeg 成片

覆盖 14 个行业分类，点「从市场创建」就落到你自己的实例里，之后可以随意改提示词、 换模型、加技能。创好的专家还能共享给同事，谁用都是同一套配置。

技能市场：装一个，多一项本事

这是把「什么都不会的聊天框」变成「什么都会干的同事」的地方。技能包里写着明确的 使用场景、输入输出和操作步骤，专家加载后就知道这类活该怎么干—— 不是靠你在提示词里手把手教。

  • 编程：编程专家（270 万次下载）、dev-expert——全栈开发、Bug 诊断、代码审查、测试用例
  • 职场文书：公文写作、标书写作、专利初稿、合同审查、中文公文排版
  • 设计与多媒体：架构图一键生成、GPT Image 生图、论文配图、视频剪辑、公众号封面
  • 数据与研究：全球文献知识库、OpenAlex、财报与量化分析、PDF 与图片文字提取
  • 生活场景：育儿大师、防骗大师、法律咨询——也有娱乐向的，按需取用

需要 Key 的技能（腾讯文档、WPS、企查查这类）会明确标出「需配置 API Key」， 不会让你装完才发现用不了。技能按「为你推荐 / 近期飙升 / 下载热榜 / 最近上新」排列， 社区装得多的东西自然排在前面。

内置连接器：填个 Key，就能动手碰你的真实系统

连接器是专家调用外部服务能力的入口。一个连接器实例 = 一份凭证 + 一个显示名称， 同一个服务可以创建多个实例（比如两个不同账号的邮箱）。填完凭证先探测再保存， 对话时按需勾选即可。

  • 办公协作：腾讯文档、腾讯会议、腾讯微云——读写文档、拉会议纪要、传文件
  • 笔记与知识：腾讯 IMA、有道云笔记、Notion
  • 出行与生活：百度地图、滴滴、携程问道、美团旅游助手、飞猪、QQ 音乐
  • 专业工具：企查查（工商与风险数据）、OpenAlex（学术检索）
  • 自托管与扩展：飞书 CLI、企业微信 CLI、Agent Mail、WeKnora、Dify—— 以及任何自定义 MCP

关键在于凭证由你保管：连接器的凭据加密后存在你这台服务器上， 不经过任何第三方；共享后同实例内的同事可选用，但只有你能编辑。

通道：在大家已经待着的群里，使唤专家

这是最容易体现价值的一步：同事不用打开任何新东西。在他们本来就在的群里 @ 一下， 专家就把活干了，做完把结果发回群里。

  • 微信：通过 iLink Bot 接收与回复私聊、群聊消息
  • 企业微信：应用消息、单聊与群聊——最适合团队内部使用
  • 飞书 / 钉钉：私聊与群聊，消息双向同步到专家
  • QQ：机器人频道，接入后可在 QQ 中直接对话
  • 元宝 / 小艺：把专家能力接入腾讯元宝会话，或经 A2A 协议与语音助手互通
  • MQTT：把 IoT 设备或机器人的消息路由给专家

所有入口——Web 控制台、IM、定时任务——走的是同一条处理链路： 同一套工具、同样的技能、同样的记忆。所以「控制台里能做到的事，群里也做得到」， 不会出现两套行为。群里的每条消息都带发送者身份，只有授权名单里的人能触发工具调用与写文件。

常见问题

{{NAME_ZH}}是开源的吗？

是。{{NAME_ZH}}以 MIT 协议发布，许可与版权声明随源码一并提供。 代码公开，你可以自行审计、修改与分发。

数据会存在哪里？会出内网吗？

全部在你部署的那台机器上，默认 %USERPROFILE%\.octop：账号、专家、对话、记忆、技能与模型配置都在这里。 程序本身不会把内容联网上报；要不要接外部服务由你决定。

忘记密码怎么办？

登录页的「忘记密码」在本机部署下会直接给出重置表单，不用开终端；服务端部署仍会显示命令行方式。 这个接口只在服务绑定回环地址、且本机只有一个账号时才开放。

有 macOS 或 Linux 版吗？

目前只发布 Windows x64 的安装版与便携版。macOS / Linux 与 ARM64 的构建定义都在仓库里， 尚未逐个平台走完安装验收，所以暂不列为可下载项。

支持多用户吗？

支持。JWT 多用户隔离，管理员可以按成员分配不同的专家、知识库与通道，工作区互不可见。

能接哪些聊天软件？

飞书、钉钉、企业微信、QQ、微信，以及 Web 控制台本身。任何入口的消息都归一到同一条处理管线， 工具调用、定时任务与记忆的行为一致。

有企业支持吗？

面向企业内网自托管部署。问题反馈与实施支持请通过 问题反馈 联系我们。
